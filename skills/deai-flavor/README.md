# 去除 AI 味（deai-flavor）

给机器人自己用的一把尺子：写长文之前先把草稿过一遍，把「AI 腔」挑出来。

## 它检查什么（四层）

| 层 | 查什么 | 谁来做 |
|---|---|---|
| L1 硬规则 | 禁用词（赋能/闭环/抓手/底层逻辑/猛地/狠狠/仿佛/瞬间/稳稳…）、套路句式（不是…而是…／首先…其次…最后）、滥用标点（破折号连用、感叹号成串、分号） | **工具**，正则扫描，零容忍 |
| L2 风格一致性 | 平均句长、长句占比、长短句是否交错、开头是不是不具体的概括句 | **工具**给统计，模型改 |
| L3 内容质量 | 空洞大词（生态/链路/心智/维度/协同…）、通篇有没有具体的人事数字 | **工具**给信号，模型补 |
| L4 活人感终审 | 通读一遍：像不像人在群里随口说的 | **模型**，工具给不出 |

## 处理流程

先诊断（轻 / 中 / 重）→ 三步改写（① 去泛化 ② 去书面化 ③ 回自然感）→ 把新稿再传一次复检，对比硬伤数。

## 为什么是「技能」不是「插件」

判据就一条：规则能不能写死。L1 写得死，但 L4「像不像真人」和改写本身要理解人话 ——
所以判断权交给模型，做成 LLM 型技能（`registerTool` + 提示词片段）。

- 工具 `deai-flavor__deai_check`：确定性那半，给尺子。
- `skill.json` 里的 `prompt.sections`：让模型写长文前自发自查，不等它想起来调工具。
- 改写：模型动笔。工具不替它写。

## 设置项（控制台 → 技能 → 去除 AI 味）

- **判定严格度**：loose（群聊短句）/ normal（默认）/ strict（长文正式稿）
- **额外的禁用词**：自己拉黑的词，逗号/空格/换行分隔，按「命中即硬伤」处理
- **附带 L2/L3/L4 自检提示**：默认开；关掉只返回硬伤清单，省 token
- **单次检查字数上限**：默认 4000

## 怎么手动验一次

群里（或让机器人）发一句：「把这段话去掉 AI 味：值得注意的是，这不是工具而是赋能的闭环。」

它应该先调自检工具，拿到「重」和逐处命中，再给出改过的短句。
