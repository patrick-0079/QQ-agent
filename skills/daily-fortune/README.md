# 每日运势（daily-fortune）

给 QQ Agent 用的一个技能：抽每日签 —— 等级 + 综合分 + 宜 + 忌 + 幸运色/数字/方位 + 一句话，
再配一张合气氛的 P 站二次元图，**合并成同一条消息**发出去。

只在**私聊**或**被 @ / 拍了拍**时给；群里普通聊天不会自己冒出来。

## 安装

1. 把整个 `daily-fortune` 文件夹放到：

   ```
   <QQ Agent 安装目录>\resources\app\skills\
   ```

   放完应该是：

   ```
   skills\daily-fortune\skill.json
   skills\daily-fortune\index.js
   ```

2. 热重载开着的话**落地即生效**（默认就是开的）。没有的话重启 QQ Agent。

装好后到「技能」页应该能看到一张叫 **每日运势 v1.0.0** 的卡片，状态「生效中」，
右边有个齿轮（4 项设置）。模型那边看到两个工具：`daily-fortune__today`（抽签）和
`daily-fortune__send`（把文案和配图合并成一条发出去）。

## 先说清楚：配图是「软依赖」

配图是**借隔壁 `pixiv-search` 技能**里的 `py/cli.py` 去搜、去下的（同一个爬虫，没有重复实现）。

- 对方**装了** `pixiv-search` → 运势带图，一条消息里图文都有。
- 对方**没装** → 运势照常能抽，**只是没有图**，会退化成一条纯文字，不会报错。

所以它单独也能用，不用非得凑齐两个技能。

## 它长什么样

```
🔮【今日运势】2026-09-30 周三 · 为「某某」抽的签
🎉 签位：大吉 ★★★★★ · 综合 96 分
✅ 宜：吃顿好的、学个新词、把拖很久的事做掉
🚫 忌：把话说太满、刷手机到半夜
🍀 幸运色：深灰 · 🔢 幸运数字：3 · 🧭 幸运方位：西北
💫 一句话：想做的事今天推一把，会比平时顺很多。
```

（实际发出去时，模型会用自己的口吻把它说成一段话，并把表情带过去。）

**同一天同一个人，签是固定的** —— 问两次不会变，第二天自动换新。
抽签用「日期 + 人名」做种子算出来的，没有随机数、不落盘、没有定时器。

## 设置（4 项）

| 设置 | 默认 | 作用 |
|---|---|---|
| 启用每日运势 | 开 | 总开关 |
| 群里只在被点名时给 | 开 | 关掉后群里随机接话时也可能给 |
| 配一张 P 站图 | 开 | 关掉则只发文字 |
| 显示幸运色/数字/方位 | 开 | 关掉回复更短 |

## 触发闸门（为什么群里不乱说话）

技能自己会读宿主给的响应档位：

| 场景 | 行为 |
|---|---|
| 私聊 | 给 |
| 群里被 @ / 拍了拍 | 给 |
| 群里关键词命中 / 随机接话 | 拒绝，并让模型当作没发生 |

## 隐私

- 不含任何账号、密钥、Cookie、聊天记录或统计信息。
- 不落盘、不写状态文件；临时配图下到**系统临时目录**（`%TEMP%\qqa-daily-fortune`），
  最多留 12 张，超出自动删旧的。
- 不联网做任何事，除了去 P 站索引搜图（那是 `pixiv-search` 的爬虫干的）。
