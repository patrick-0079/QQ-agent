# 不要写混响/回声/均衡这类"后期效果"词（会干扰生成），也不要写互相矛盾的特征。

# 迭代记录：
#   第 1 版 "少女音，中高音，清脆偏软…"                → 反馈：太成熟
#   第 2 版（B）"中音，软糯，胸腔的闷响，像刚睡醒…"      → 反馈：语气可以，音色还是太成熟
#   第 3 版（C）去掉厚重感，走日式幼态清亮，保留 B 的懒散 → 反馈：C2 接近了，但还不对
#   第 4 版（当前）参考《鸣潮》釉瑚的声线：高声线幼态萝莉 + 语速快而跳 + 句尾上扬带笑
#                + 爱拖软尾音 + 得意卖弄、偶尔突然害羞——把 B 的"懒散吞尾音"换成她的"上扬带笑"
日式动画里的幼态萝莉音：音调高、音色清亮细嫩，带一点奶音的稚气，共鸣位置靠前、完全没有厚度。语速偏快、轻快跳跃，短句连发，句尾轻轻上扬并带笑意，尾音常拖长一点点，像随时在得意地卖弄。情绪外露、活泼俏皮，偶尔会突然害羞把声音收小。不是播音腔，也不要甜腻发嗲。
