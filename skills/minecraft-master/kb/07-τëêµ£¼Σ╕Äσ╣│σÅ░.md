# 版本、平台与联机

> 来源：https://zh.minecraft.wiki/w/版本

## 三个"我的世界"

- **Java 版**：PC（Windows/Mac/Linux），用官方启动器或第三方启动器，模组生态最丰富。
- **基岩版（Bedrock）**：手机、主机、Windows 商店版，跨平台联机方便，红石和刷怪机制与 Java 不同。
- **网易中国版**：国内代理，基于基岩版，服务器与联机在国内容易，但**不与国际版互通**，模组来源也不同。

问问题时先分清是哪个：同一个"怎么做"在三者上答案可能完全不同。

## 常见版本都用来干什么（社区共识）

- **1.7.10**：老模组黄金版本，很多经典 mod 只支持它。
- **1.8.9**：PVP 经典版本（没有后续的战斗机制改动）。
- **1.12.2**：模组生态最大，整合包最多的版本。
- **1.16.5**：下界更新后最稳定的模组版本之一。
- **1.20.1 / 1.21.x**：目前较新的主流版本。

## 启动器

- **官方启动器**：正版必需。
- **HMCL / PCL2**：国内最常用的第三方启动器，能管理多版本、装模组和整合包。

## 服务器

- **原版服务端**：官方提供。
- **Paper / Spigot**：装插件的服务端（生存服、小游戏服常见）。
- **Fabric / Forge**：装模组的服务端（要和你客户端的模组一致）。

## 联机方式

- 局域网：一人开"对局域网开放"，同网络的人直接进。
- 远程联机：内网穿透（如各种隧道服务）或租服务器/用平台联机。
- 正版服务器：需要正版账号验证；离线服（盗版服）则不验证。

## 踩坑提醒

- **同一个种子在 Java 版和基岩版生成的世界不一样**，别指望两边一模一样。
- 存档不通用：Java 与基岩版的存档格式不同。
- 模组要看版本号对不对得上，装错版本直接崩溃。
