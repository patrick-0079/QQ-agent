# 资源、工具与常用合成

> 来源：https://zh.minecraft.wiki/w/合成

## 工具等级与能挖什么（最容易记错的地方）

| 工具 | 能挖 |
|---|---|
| 手 | 木头、泥土、沙子、沙砾、南瓜 |
| 木镐 / 金镐 | 石头、煤矿 |
| 石镐 | 铁、铜、青金石 |
| 铁镐 | 钻石、金、红石、绿宝石 |
| 钻石镐 | 黑曜石、远古残骸 |
| 下界合金镐 | 全部（黑曜石、远古残骸也更快） |

工具等级从低到高：**木 < 石 < 铁 < 钻石 < 下界合金**（金镐挖得快但耐久极低，属于特殊情况）。

## 基础合成（背这些就够了）

- 原木 → 4 木板；2 木板（竖着放）→ 4 木棍
- 工作台：4 木板
- 熔炉：8 圆石
- 箱子：8 木板
- 火把：1 煤炭/木炭 + 1 木棍 → 4 个
- 床：3 羊毛 + 3 木板
- 桶：3 铁锭
- 盾牌：6 木板 + 1 铁锭
- 铁傀儡：4 铁块 + 1 南瓜（用来守家）
- 附魔台：4 黑曜石 + 2 钻石 + 1 书
- 铁砧：3 铁块 + 4 铁锭
- 信标：5 玻璃 + 3 黑曜石 + 1 下界之星

## 装备

- 钻石镐：3 钻石 + 2 木棍；钻石剑：2 钻石 + 1 木棍；钻石盔甲各部位 5/8/7/4 钻石
- **下界合金**：4 个下界合金碎片（远古残骸烧炼得到）+ 4 个金锭 → 1 个下界合金锭；
  再拿它和钻石装备在**锻造台**上合成下界合金装备。下界合金不能直接合成工具。
- 下界合金装备：耐久更高、不会被岩浆烧掉、有击退抗性 —— 这才是真正的毕业装。

## 提醒

配方的**精确形状**（比如剑是竖着三格、锄是斜着）不要凭记忆答，拿不准就让群友查 Wiki 或用 wiki_page 看原页。
