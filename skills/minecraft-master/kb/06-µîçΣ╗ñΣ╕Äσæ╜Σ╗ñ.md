# 常用指令

> 来源：https://zh.minecraft.wiki/w/命令

## 前提

- 单人游戏要在**创建世界时开启作弊**，或在局域网开放时允许作弊；服务器需要 OP 权限。
- 指令以 `/` 开头（聊天框里输入）。

## 目标选择器

- `@s` 自己、`@p` 最近的玩家、`@a` 所有玩家、`@r` 随机一个玩家、`@e` 所有实体。

## 最常用的

- `/gamemode creative`（简写 `/gamemode c`）：切创造模式；`survival` / `s` 切生存。
- `/tp @s 100 64 200`：传送到指定坐标。
- `/give @s minecraft:diamond 64`：给自己 64 个钻石。
- `/time set day` / `/time set night`：切白天 / 夜晚。
- `/weather clear`：晴天。
- `/difficulty peaceful`：和平难度（不刷敌对生物）。
- `/seed`：看当前世界的种子。
- `/locate structure village`：定位最近的村庄（也能查 fortress、stronghold、ancient_city 等）。

## 保命/常用游戏规则

- `/gamerule keepInventory true`：**死亡不掉落**（新手最该开的）。
- `/gamerule doDaylightCycle false`：时间停止流动。
- `/gamerule mobGriefing false`：苦力怕不炸地形。

## 进阶

- `/effect give @s minecraft:speed 60 2`：给自己加速 60 秒、等级 2。
- `/enchant @s minecraft:sharpness 5`：给手上的物品附魔。
- `/summon minecraft:zombie`：召唤一只僵尸（可以带坐标和 NBT）。
- `/setblock` / `/fill`：放一个方块 / 填一片区域。
- `/execute`：条件执行，功能最强也最难（1.13 之后语法变化很大，老教程里的写法多数已经不能用了）。

## 注意

指令语法在 **Java 版和基岩版之间有差异**，不同版本（尤其 1.13 前后）也变过。
群友说照着敲报错时，先问清楚是哪个版本，再让他核对一遍语法。
