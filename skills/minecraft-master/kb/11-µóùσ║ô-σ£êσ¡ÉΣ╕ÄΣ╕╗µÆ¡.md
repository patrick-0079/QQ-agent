# 梗库：圈子与主播

> 来源：https://mzh.moegirl.org.cn/

MC 社区、UP 主、服务器事件与圈内黑话。**一行一条**，已改写为速查条目（不是原文照抄）。
涉及真人的只解释词义、**不评价人**；带【慎用】的别主动提。

## 一、官方提示与标语

- **别杀海豚，你这个怪物**：基岩版的加载提示原文，因为直接对屏幕前的玩家喊话而印象深刻。反向恶搞："别杀怪物，你这个海豚！"
- **U-Word**：闪烁标语"Doesn't use the U-Word!"，没人知道 U-Word 指谁，猜是避讳 Unity 引擎。
- **元素周期表**：一批以化学元素命名的性能优化模组，合称"元素周期表"。
- **移除了 Herobrine**：更新日志里的长期玩笑，隔几个版本就"再移除一次"。（详见《官方彩蛋与出处》）

## 二、出圈大梗（群里最常引用）

- **还是 PVP 大佬**：2020 年"GRW 团队招生"视频，命令方块被反复触发，这句话连刷打断节奏，加上一堆失误，2024 年初搬运到 B 站后爆火。
- **大炮做好了不在这放珍珠是什么意思**：TIS 服务器黑山大叔用返程珍珠炮时随口一句，结果炮当场炸膛，三千多米加载线白铺。他后来又炸过几次，成了"用炮必炸"。设计者 Fallen_Breath 反感被狂刷：【慎用·适度】。
- **创哥理赔**：生存模式里开创造挽回损失，出自 nor 叔。也指末地传送门框架生成不全、只能开创造补齐。
- **舰长行为**：UP 主"和谐号舰长"疯狂虐待村民，泛指虐村民（用 TNT、岩浆、剑都算）。
- **看我超级搭路，no！！！**：起床战争视频里徒弟喊完"看我超级搭路"就踩空掉虚空，师父接着喊"看我黑客搭路"也掉下去。
- **美国概率哥 / 我的世界极小概率事件**：外网主播 npesta 打《几何冲刺》13 万次才过关的猴叫素材，被套在 MC"极小概率事件"视频上。固定套路：基泥苔煤、鲑鱼桶落地水、望远镜看地形、标注"概率 0.000…114514%"。
- **山西人击杀凋灵骷髅获取煤炭**：一份褐煤行业报告把 MC 的煤炭获取方式抄了进去（"击杀凋灵骷髅获得 1-3 个"），网友调侃山西的煤是打凋灵骷髅来的。同类还有"河北钢铁厂击败铁傀儡"（无实证）、"河南小麦乱入骨粉"（F12 改网页）。
- **高科技还原伦敦大火**：2016 年央视报道博物馆还原伦敦大火，前半段画面全是 MC 宣传片，还称之为"声光电技术"。
- **一定是 OptiFine 干的！**：OptiFine 兼容性差、见谁崩谁，游戏一崩先怀疑它，被做成表情包。
- **我不搬你们看什么**：指责搬运 UP 主的句式（"我不搬你们看什么"）。
- **我的世界芯**：恶搞《我的中国芯》的海报，往里塞 MC 的各种特性。
- **我拉的世**：泰拉瑞亚 + MC 的谐音；再加饥荒就是"我世拉饥"。
- **无 oo 者，以 xx 代之**：教程弹幕里的材料替代建议（"没有红树木可用绯红木"），也有故意误导的（"无金块者，以钻石块代之"）。
- **Xk 打钱**：XeKr 的"方纹淡彩"材质包被别的 UP 主用了，弹幕就喊打钱（调侃，不是真推广）。
- **袭击 / 现在谁才是掠夺者**：玩家洗劫村庄的行为（搜刮、杀村民、找铁哥借铁），弹幕刷"袭击 - 剩余 X 名袭击者"。
- **自古起床先灭黄，黄队不灭三队亡**：某服务器起床战争黄队大佬多，流传成俗语。
- **此生无悔入 MC，来世还做方块人**：仿"此生无悔入东方"的信仰口号，2017 年前后流行，现在多用于怀旧。

## 三、主播、UP 主与名场面

- **游 戏 结 束**：Dream 的猎人游戏里，他一撸到木头就等于锁定胜局，弹幕刷"游戏结束"。
- **哦还活着**：搬运外网 MC 视频的 UP 主，特征是无配音、轻音乐、拿材质包/模组整活，见到同类视频就提他。
- **曲柄仙人**：机械动力 + 车万女仆模组，让女仆摇曲柄供能的"血汗工厂"整活，梗图主角多是酒狐。
- **炮爷出击**：guiwow 早年用 TNT 把自己炸飞（嘴里念"炮爷出击，只为正义"却屡屡失败），现在泛指脚下放 TNT 炸飞自己。
- **这 oo 秒，我录了 xx 秒**：高难度跑酷视频的标题党，录制时间远超视频时长，结尾必跳崖触发不死图腾。
- **逃离清华**：躲避"清华教授"追捕的地图题材。
- **挑战跑酷不踩黄色**：立下"不踩黄色方块"的规矩，失误一次就说"这个不算因为…"。
- **再见 2025，你好 2026**：跨年固定节目：点燃摆成去年年份的 TNT，炸出今年的数字。
- **跑酷电子榨菜**：拿 MC 跑酷当背景、配 AI 语音包讲知识或念定型文的下饭视频。
- **亻尔 女子（你好）**：把"你好"拆成两个字，视频里每翻一次车就配一遍，衍生出"手戈 爱 亻尔"（我爱你）等拆字标题。
- **你能在得了痴呆症的情况下通关 Minecraft 吗**：油管主 AJSimSim 的系列视频，四分钟还在原地打转、连自己砍没砍过树都不记得。
- **杂兵**：某短视频博主说 MC"暴力恐怖"，列举的怪物里有根本不存在的"杂兵"。【慎用·别主动提】
- **加速火把**：一个能加快游戏进程的模组。某主播录模组视频特别爱用，被评论区吐槽成梗（连头像都跟着倒霉），现在泛指"用模组无脑提速"。
- **小木 / Minecraft_小木**：孤岛生存被扒出作弊（箱子只刷铁锭、地形异常），后来开服圈钱被玩家炸服，销号跑路。【慎用·只解释词义，不评价人】

## 四、外挂与圈内黑话

- **纪 / 纪狗**：外挂的代称。浪仔对着外挂玩家喊"纪狗，气死我了"，还拿了把菜刀。【慎用·带侮辱性】
- **Vape / 维普**：著名的 Java 版外挂软件，主播放它的 HUD 调侃自己技术好。【慎用·带侮辱性】
- **杀戮光环 / killaura**：自动锁敌外挂，相当于别的游戏的自瞄，可群伤。
- **狂笑的蛇将写散文**：一个网易随机 ID 的外挂玩家，低头高速转圈做伪 AOE，被比作那维莱特和 CS 陀螺挂。
- **张哥之足球梦想**：开挂还很菜的玩家代称。掉进虚空前很狂，掉下去就求人把他带上来。
- **Highpingxel / Haxpixel**：Hypixel 的调侃名，前者吐槽延迟（ping）和丢包（loss），后者吐槽外挂（hax）多。
- **jvav**：早年某小学生"我会 jvav"，成了把 Java 打错的代称。
- **L**：Loser，比 noob 更有侮辱性。【慎用·带侮辱性】
- **石粒**：籽岷把"实力"说成"石粒"，"石剑（实践）是检验真理的唯一标准"。
- **腐竹**："服主"的谐音。
- **2 变 2 态**：2b2t 的谐音，形容服务器毫无秩序。
- **450**：12dora 的服务器当年要玩家交 450 元当"机房电费"——"你不交 450 谁也保不了你"。

## 五、缩写与专有称呼

- **MC 的 C 不发音**：一堆诅咒饰品 = "MC 没有 C"，谐音"抖 M"。
- **MC 死掉了**：怀旧党嫌新版改太多、老模组停在 1.7.10 / 1.12.2；Notch 本人也说过 MC 死了。
- **Minecraft 风格**：泛指 3D 像素风，很多不是 MC 的作品被误认（比如《我的三体》）。
- **瑞典原神**：把 MC 比作"瑞典原神"，还配了对照表（原石→圆石、风之翼→鞘翅、祈愿→钓鱼）。【慎用·易引战】
- **老一辈的数值没轻没重**：1.7.10 / 1.8 时代的模组动辄"七百多京"伤害。
- **搂 4 搂 / 搂 6 搂**：`§4§l` 这类格式化代码在 GBK 下显示成"搂"，于是神器的名字变成"搂4搂l"（=红色加粗）、"搂6"（=金色）。
- **水槽包**：把一大堆模组随便塞进整合包、不做兼容和平衡，来自"除了厨房水槽啥都用上了"。
- **东方矿工艺**：把东方 Project 和 MC 结合起来的作品/整合包，早年常见，现在少用了。

## 六、【慎用】别主动提的

- **一战 / 二战**：MC 玩家与迷你世界玩家多年骂战被叫"一战"，参与者自称"一战老兵"。**别站队、别主动提。**
- **鸣潮（mc）**：有人把鸣潮的拼音缩写也说成 mc，两拨人因此别扭。**别硬混。**
- **五人组魔咒**：MC 组合"组五人必塌房"的说法（涉及真人争议）。**别主动提。**
- **Ryluu**：AI 配音假扮"美国女孩"打 Hypixel，被扒后成笑柄。**别拿名字调侃。**
- **闹吃 VS 古振兴**：AI 肌肉男 + 《FNF》说唱 battle，源自 MC 与迷你世界骂战的老笑话。**容易引战。**
