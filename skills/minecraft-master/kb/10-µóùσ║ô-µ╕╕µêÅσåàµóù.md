# 梗库：游戏内梗

> 来源：https://mzh.moegirl.org.cn/

游戏机制、操作习惯、界面提示衍生出的梗。**一行一条**，已改写为速查条目（不是原文照抄）。
接梗一句就够；不确定就说不确定，别编出处。

## 一、这是特性，不是 bug

- **特性 / 这不是 bug**：官方不修的 bug 在 MC 圈叫"游戏特性"。场景：任何诡异现象、掉进自己挖的坑。
- **刻意的游戏设计 / Intentional Game Design**：床在下界或末地炸死人时的死亡消息，原文可点，跳到当年那个被官方以「按预期工作」关闭的漏洞报告。
- **Bugjump**：Mojang 的调侃外号，Mo(bug)+jang(jump)，吐槽跳票 + bug 只修一半。同类的还有**麻将**（Mahjong≈Mojang，也是开发商外号，j 在瑞典语念"y"）。
- **科学**：MC 里反物理的现象（落地水、床在下界爆炸、浮空树），一句"这不符合科学"就到位。
- **牛顿的眼泪**：方块能浮空、水不流走，调侃牛顿看了要哭。
- **圆**：MC 全是方块，"MC 里没有圆"。看到圆形就刷"世界末日"。补：望远镜刚加时视野是圆的，下一个快照官方自己改成方形。
- **按住 W 开始思索**：机械动力等科技模组的物品提示"按住 W 开始思索"，常配 🤔 使用。
- **BL**：Java 版 F3 调试屏里的 BL 是亮度（Block Light），不是 BL 题材；MCPE 圈 BL 指启动器 BlockLauncher。常被误会。
- **按 Q 释放剑气（剑弃）**：Q 是丢弃键，W 就在旁边，容易误按把附魔剑丢出去。装备落地时刷这句。
- **调戏物品栏**：B 站底端弹幕打「调 戏 物 品 栏」正好盖住五个格子，2019 年前后流行。
- **64 进制**：一组=64 个，玩家默认计数单位。
- **2+2=3**：铁砧把两把同等级附魔合并成高一级（时运 II+时运 II=时运 III），不是相加。
- **香草**：Vanilla 直译，指"原版"，不是那个香草。
- **负魔**：反向附魔的恶搞（模组/插件实现），如"耐久下降""时运倒扣"。

## 二、翻译事故（随口就能玩）

- **雷石东直放站**：Redstone Repeater（红石中继器）的机翻名。2012 年有人为拿"翻译披风"批量提交错误翻译，正好没人复议，于是混进正式版。同类：**大火杆**（烈焰棒）、**床上**（床）、**黑沉沉泪**（恶魂之泪）。
- **基岩后台**：拿基岩"无法破坏"比喻视频里夹带私货、过了审就删不掉。
- **业火余烬之刃 / 炼仙金果**：文言版的下界合金剑、附魔金苹果，中二译名梗。
- **水雷艇 / 暴徒产卵 / 被困的胸部**：机翻笑话（Minecraft→水雷艇、Mob spawn→暴徒产卵、Trapped Chest→被困的胸部）。另有"海角"（披风）、"正在治愈"（经验修补）、"银鱼"（蠹虫）。
- **蠹虫 / 蠢虫**：Silverfish，字生僻，常被念成"蠢虫"。

## 三、操作与生存习惯

- **猛男 / 真男人挖矿法**：对着脚底竖直往下挖。爽但危险，掉进洞穴或岩浆，靠"落地水"救。
- **砍手岩**：基岩。早年新人发帖问"这方块怎么挖不动"，大佬答"再问砍手"。
- **要致富，先撸树**：开局第一件事，仿"要致富先修路"。
- **卑鄙的两格人**：躲在两格高的缝里戳末影人（2.9 格）或凋灵骷髅（2.4 格），它们近战打不到你。
- **万能营火**：熄灭的营火被拿去当屋檐、长椅、吊桥、木板堆，建筑党万金油。
- **麒麟臂**：玩家徒手搬熔岩、扛铁块，还永不磨损。
- **火柴盒**：萌新的长方体房子；装修过就叫"高级火柴盒"。
- **镐击**：用镐打架（伤害低），谐音"搞基"。看到用镐打人就刷"出现了！镐击"。
- **古（蛊）人的智慧**：在神殿踩到自己或基友造的陷阱时的吐槽，也叫"法老的智慧"。
- **多喝岩浆**：比"多喝热水"更狠的直男发言，因为岩浆比热水烫得多。
- **草**：MC 有草方块也有草，"草（一种方块/植物）"用来免责。
- **别人的世界**：看到大佬操作时喊，对应游戏名"我的世界"；同义"我们玩的是同一个游戏吗"。
- **20 铁**：萌新挖到 20 个铁锭发帖炫耀，"我有 20 铁，你怕不怕"。
- **我一个鸡砸出四个蛋**：鸡蛋一次砸出四只小鸡的概率是 1/256，UP 主 KL_qiqi 那声喊成了梗。
- **那是气球吗？**：用望远镜看恶魂的进度。同系列"那是鸟吗"（鹦鹉）、"那是飞机吗"（末影龙）；玩家自创版有"那是妹子吗"（猪灵）。

## 四、合成与物品

- **合成错误**：记错合成表。Dream 的"石头工作台"、Technoblade 的"线斧"（还梅开二度）、"糕蛋"（蛋糕上下放反）、"NTN"（TNT 的沙子和火药反了）、"钻石柄木镐"、"土豆柄锄头"。
- **附魔金苹果**：形容"制作精良但没人看"的视频，因为附魔金苹果稀有又强力。
- **合成天下**：MC 的别称，谐"和成天下"（槟榔品牌），调侃方块脸。
- **基泥苔煤**：基岩 + 泥土 + 苔石 + 煤炭块，谐"鸡你太美"，也是"极小概率事件"视频的固定开场。
- **钻石？**：把发光地衣、红石、青金石错看成钻石的那一瞬间。
- **我们需要再深入一些**：建下界传送门的进度名，被玩成别的意思（简中已改名"勇往直下"）。
- **猪灵是妹子**：把猪灵的鼻子看成眼睛就回不去了。
- **铜的变体**：铜块有 4 个氧化阶段、可涂蜡、还有切制/雕纹变体，光铜块就是 24 种，每种都要单独命名。吐槽时会连上"官方说不会加竖半砖"，理由是"变体太多会拖垮内存和帧率"。

## 五、赤石科技（整活红石）

- **赤石科技**：故意做没用的红石装置，"降低效率、浪费资源、折磨玩家"，对标正经的"红石科技"。后来的含义扩到任何"看似有用实则无用"的功能。
- **超级地毯机**：堆叠地毯机，一开机掉落物多到把游戏卡死。
- **草羊机**：拿船困住羊、后面加活塞和末地烛的恶趣味装置。【慎用·别主动提】
- **二叉树熔炉组 / 2048 熔炉组**：用海量漏斗搭的熔炉阵，看着能烧一堆，实际链路更长、还狂掉 TPS，堪称"服务器减速器"。
- **区块同步系列**：机器大到一路铺到世界边境，比普通赤石科技更卡。
- **铁傀儡机（铁傀儡开凿机）**：让铁傀儡 T 字来回移动的机器，配魔性 BGM，弹幕常见"随心所欲"。
- **FlceRE_V 协议**：吐槽生电圈堆多核的浮夸风，主张单核挂几天就够；机器堆片就算"违反协议"。
- **红石学多了就会丧失人性**：刷铁机把村民关起来当产能工具，从村民视角毫无人权（还有"不养闲人"处理掉多余村民）。
- **核电，轻而易举啊！**：GTNH 服务器的聊天记录，"我这核电没别的好，就是防爆做得好"→"核电，轻而易举啊"→"坏了"→全员死于核弹。

## 六、界面提示与死亡消息

- **死亡信息**：有些死法成了代称。"试图在熔岩里游泳"=被岩浆烧死；"感受到了动能"=鞘翅撞墙；"掉出了这个世界"=掉虚空；"被[刻意的游戏设计]杀死了"=床或重生锚炸死。
- **你现在不能睡觉，附近有怪物在游荡**：想跳过夜晚却被挡住，非常搞心态，常类比现实（"外面有老师在巡查"）。
- **为什么我的世界没有声音**：去百度知道问，被"心理学专家"长篇开导的名场面。（21w37a 加了音频输出选项，这 bug 才算修完。）
- **速通 WC**：看速通直播时主播去上厕所，弹幕刷"速通 WC"；去太久就恶搞成"xx 试图在厕所里游泳"。
- **军火库 xx%**：起床战争 UP 主囤满一背包资源，弹幕报进度，100% 时配"游戏结束"。
- **/back**：回死亡点的指令，也用作"这段我想再看一遍"的弹幕。
- **/hub**：回主城指令，破防退游时会打出来。
- **\*\*\***：全是星号，指网易中国版的屏蔽词，整行被替换掉。

## 七、床、传送门与"典礼"

- **弃床战争**：起床战争高手开局直接搭去主岛，根本不管自己的床（因为没床也能赢）。
- **封印解除**：床被拆掉、只剩半颗心时反而越打越猛，弹幕刷"封印解除"。
- **天堂传送门**：荧石框 + 倒水，早年萌新以为原版有"天堂"，其实那是天境模组。愚人节版本官方还做了个"异界传送门"，进去提示 404 地形未找到。
- **请不要在毕业红毯上飞来飞去**：线上 MC 毕业典礼里有人搞事（放 TNT、丢雪球），泛指在 MC 典礼/校园建筑里捣乱。
- **蘑菇毁灭末地**：末地主岛一个蘑菇 + 末影人搬运，蘑菇失控蔓延、末影龙大量复制，服务器差点报废。

## 八、别的称呼

- **EOE**：恶魂。来自它攻击前的音效。
- **绿袍尊者**：傻子村民（穿绿袍），出自《蜀山战纪》的梗。
- **飞翔使**：村民的外号，出自籽岷的小伙伴，学村民叫得像。
- **头皮屑三角洲**：玄武岩三角洲，因为空气里飘的白色粒子像头皮屑。
