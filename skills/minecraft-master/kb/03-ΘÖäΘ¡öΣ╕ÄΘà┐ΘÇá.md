# 附魔与酿造

> 来源：https://zh.minecraft.wiki/w/附魔

## 附魔台怎么到 30 级

- 附魔台周围摆**最多 15 个书架**：书架与附魔台同层或高一层，中间隔 1 格空气（书架的摆放位置很讲究，隔半格都不算）。
- 15 个书架 → 最高出现 30 级选项。
- 每次附魔消耗青金石：1 级选项 1 个、2 级 2 个、3 级 3 个，同时扣掉等量经验等级。
- 附魔台只会给**随机**的魔咒组合，想精准要某个魔咒得反复刷或找村民交易附魔书。

## 常用魔咒

- 武器：锋利 V、亡灵杀手 V、节肢杀手 V、火焰附加、击退、抢夺 III
- 工具：效率 V、耐久 III、时运 III、精准采集、经验修补
- 盔甲：保护 IV（通用）、摔落保护 IV、火焰保护 IV、水下呼吸、深海探索者
- 弓：力量 V、无限、冲击、火矢

**经验修补**和**无限**只能通过附魔书（钓鱼、村民交易、地牢箱子）拿到，附魔台刷不出来。

## 铁砧

- 用途：修复耐久、合并附魔书、给物品改名。
- 每次合并会累积"过于昂贵"的惩罚，同一件装备反复修会越来越贵；**尽量一次成型**，别拿它当无限修复机。

## 酿造（药水）

- 酿造台：1 个烈焰棒 + 3 个圆石。
- 燃料是**烈焰粉**，每瓶药水酿造要 20 秒。
- 基础起点：水瓶 + 下界疣 → **粗制的药水**（几乎所有药水都从它开始）。

| 想要的效果 | 加什么 |
|---|---|
| 力量 | 烈焰粉 |
| 迅捷 | 糖 |
| 抗火 | 岩浆膏 |
| 夜视 | 金胡萝卜 |
| 治疗（瞬回） | 闪烁的西瓜 |
| 水肺 | 河豚 |
| 中毒 | 蜘蛛眼 |
| 伤害（瞬伤） | 发酵蛛眼 |
| 虚弱 | 发酵蛛眼 |
| 缓慢 | 发酵蛛眼 + 迅捷/跳跃药水 |

## 药水改造

- **延长**时间：加红石
- **强化**效果：加萤石（部分效果不能强化）
- **喷溅**（范围）：加火药
- **滞留**（留在地上成云）：加龙息

酿造顺序很关键：先加主材料做成效果药水，再决定要不要红石/萤石/火药，顺序错了会变成"浑浊的药水"。
