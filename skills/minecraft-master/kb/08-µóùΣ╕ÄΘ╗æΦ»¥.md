# 梗与黑话

> 来源：https://zh.minecraft.wiki/

MC 圈的黑话、外号、接龙梗、社区文化。**一行一条，带出处**。
接梗时一句就够，别连发三条；不认识就说不认识，别硬接。

## 一、接龙梗：对方只发一个词，是在等你接下半句

这类不是"问你这是什么"，是点一句、等你接。看到就**直接接上：别解释、别反问、别扯回刚才的话题**。

- **Creeper? / 苦力怕?** → 接「aww man」。出处：CaptainSparklez《Revenge》开篇，官方 1.16 把它做成主菜单标语第 399 条。
- **aww man** → 把「Creeper?」接回去，来回都成立。
- **这不是 bug** → 「这是特性」。
- **这是特性** → 「这不是 bug」已经说过了，回一句「特性」也行。
- **嘶—— / 嘶** → 苦力怕点引信。接「boom」「要炸了」「快跑」。
- **钻石！/ Diamonds!** → 挖到钻石的喊声。接「发财了」。
- **我是史蒂夫 / I am Steve** → 电影里的台词，接「对，你就是史蒂夫」。
- **别往下挖 / Never dig down** → 官方标语第 106 条，指垂直下挖会撞进洞穴、岩浆、刷怪房。接「我偏要挖」。
- **移除了 Herobrine** → 官方更新日志的长期玩笑，看到就接「下次更新又会移除一次」。

## 二、生物与物品外号（群友几乎只用外号）

- **苦力怕 / 爬行者 / Creeper**：靠近「嘶——」一声后自爆，MC 的吉祥物。
- **小黑 / 末影人 / Enderman**：紫色眼睛，你直视它就会被打，会瞬移搬方块。
- **小白 / 骷髅 / Skeleton**：射箭，白天会被晒。
- **僵尸猪灵 / 僵尸猪人**：下界的和平生物，打一只惹一群（老玩家仍叫"猪人"）。
- **凋灵 / Wither**：三个头，召唤出来会追着你打。
- **铁哥 / 铁傀儡**：村庄保镖，被玩家当免费铁锭来源。
- **村民 / 绿袍子 / 提款机**：靠交易换附魔书、钻石装备，老玩家发家全靠它。
- **刌民 / 灾厄村民 / Illager**：掠夺者、卫道士、唤魔者那一族。
- **末影龙 / 龙 / Ender Dragon**：末地 BOSS，打完能拿龙蛋。
- **下界合金**：目前毕业装材料，钻石早就不是天花板了。
- **三叉戟 / 鞘翅 / 不死图腾**：三大实用件，图腾是保命的，鞘翅是飞行的。

## 三、玩法黑话

- **挖三填一**：夜里没床，往下挖三格、头顶堵一格躲怪。形容"苟住""应急操作"。
- **床是用来炸的 / 床炸**：床在下界和末地使用会爆炸，老玩家拿它开矿、炸末影龙。查「床为什么炸」就是这个。
- **刷铁机 / 刷怪塔 / 溺尸塔**：自动化产资源的机器，红石党的入门作品。
- **三格跳 / parkour**：跑酷的基本跳法，老手靠它秀走位。
- **速通 / speedrun**：比谁更快通关，分随机种子和固定种子。
- **极限模式 / hardcore**：一命，死了不能复活，通常只敢看别人玩。
- **手撸树 / 先砍树**：开局第一件事，形容"从最基础开始"。
- **火把神教**：到处插火把防刷怪，插满视线所及的地方。
- **红石大佬的尽头是造 CPU**：红石能搭计算器甚至处理器，技术流终点梗。
- **附魔台摆 15 书架**：满级附魔的标准配置，老玩家张口就来。
- **空岛 / 起床战争 / PVP**：常见服务器玩法，Hypixel 是代表。
- **下矿**：专门去挖矿的一趟，常配"挖了三小时啥也没有"。
- **龟壳头盔 / 蛋糕 / 绿宝石**：绿宝石是村民货币，不是装备材料（新手最常搞错）。

## 四、社区与主播（说错容易得罪人，只说事实）

- **Technoblade never dies**：Mojang 官方纪念，1.19.1 加入的同名标语；他的猪皮肤皇冠被加到游戏猪身上，也出现在电影里。
- **Herobrine / 白眼人**：都市传说，从没在正式版存在过，但官方持续玩"已移除"的梗。
- **2b2t**：最古老的无政府服务器，进服要排几小时队，以废墟和混乱闻名。
- **Dream**：速通被质疑过概率作弊，这件事是圈内公认的争议点，别替任何一方站台。
- **Minceraft**：主菜单有 0.01% 概率把 Minecraft 显示成 Minceraft，官方自己玩错字梗。
- **电影梗**：杰克·布莱克演的《A Minecraft Movie》，"Lava Chicken"和"鸡骑士"是电影带火的新梗，影院里观众起哄就是这个。
- **网易版 / 中国版 vs 国际版**：两派互相调侃就行，**别踩人**，这条最容易引战。

## 五、抽象口头禅（不用有出处，用对场合就行）

- 「这游戏没有 bug，只有特性」
- 「又卡了」→ 多指服务器或显卡，不是游戏 bug
- 「我先挖两格」→ 慌张时先苟住
- 「谁放的 TNT」→ 场面炸了的时候
- 「我的世界不是游戏，是童年」→ 怀旧向，聊版本或第一次玩时用

## 六、使用原则

1. 一次一句，别连着抖三个梗。
2. 对方认真问技术问题时，先把问题答清楚，梗放最后一句。
3. 不认识就老实说"这梗我没跟上"，别硬接、别编出处。
4. **别把梗词当正经名词去答**：把「Creeper?」当成在问"苦力怕是什么"，就完全接不上了。
