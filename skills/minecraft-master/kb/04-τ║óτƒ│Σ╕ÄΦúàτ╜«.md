# 红石基础与常见装置

> 来源：https://zh.minecraft.wiki/w/红石电路

## 元件

- **红石粉**：铺在地上当导线，信号强度 0~15，每走一格衰减 1。
- **红石火把**：常亮电源，也能做反相器（输入通电 → 输出断电）。
- **中继器**：单向传输、可延长信号、延迟 1~4 tick（0.1~0.4 秒），右键切换延迟。
- **比较器**：比较两路信号强度，可做计时器、容器检测（箱子满了才输出）。
- **活塞 / 粘性活塞**：推动方块（最多 12 格）；粘性活塞能拉回来。
- **侦测器**：检测前方方块状态变化，输出一个短脉冲（做自动农场最常用）。
- **漏斗**：自动收集与传输物品，可限制速度。
- **发射器 / 投掷器**：发射器会"用"物品（射箭、倒水、放船），投掷器只是丢出去。
- **红石块**：常亮的信号源，可当电源。
- **按钮 / 拉杆 / 压力板 / 绊线钩**：手动或感应触发。

## 常见装置与思路

- **自动甘蔗机 / 竹子机**：侦测器 + 活塞，作物长高就推掉。
- **刷怪塔**：黑暗空间让怪生成，用漏斗收集掉落物；效率看刷怪面积和离地面的高度（24~128 格之外才刷怪）。
- **自动熔炉**：漏斗进料 + 燃料槽 + 输出箱。
- **活塞门 / 隐藏门**：粘性活塞 + 红石粉的经典组合。
- **TNT 复制**（视版本，属于特性利用）与 **自动农场** 是红石入门后的两个大方向。

## Java 与基岩的差异（最容易吵起来的地方）

- **准连接（quasi-connectivity）只在 Java 版有**：活塞会被"隔一格的信号"意外激活。
- 红石线朝向、中继器锁存、粘性活塞行为在两版之间不完全一致。
- 同一个红石作品从 Java 搬到基岩版**大概率不能用**，需要重做。

所以群友问红石时，先确认是 Java 还是基岩；要找教程就搜对应版本的关键词。
