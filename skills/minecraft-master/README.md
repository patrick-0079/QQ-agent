# 我的世界大师（minecraft-master）

让 QQ 机器人在被叫到时按《我的世界》老玩家的水准回答问题：查 Wiki、给攻略视频、接梗。

- **目录**：`skills/minecraft-master/`（LLM 型技能 —— 注册工具给模型，用不用由模型自己判断）
- **类型判定**：需要理解"群友到底问什么"（同一句话可能要查条目、也可能只需要常识），规则写不死 → 技能而不是插件
- **默认开关**：启用；**默认只在被 @ / 戳一戳 / 私聊时生效**（不占平时提示词）

## 四个工具

| 工具 | 作用 | 联网 |
|---|---|---|
| `wiki_search` | 检索 zh.minecraft.wiki 条目，**标题命中优先**（前缀检索 + 全文检索合并） | 是 |
| `wiki_page` | 读指定条目的正文纯文本（可限字数） | 是 |
| `kb_search` | 查内置速查库（11 个主题，离线秒回；含四篇梗资料：《梗与黑话》《官方彩蛋与出处》《梗库：游戏内梗》《梗库：圈子与主播》） | 否 |
| `bilibili_search` | 搜 B 站视频，按 **播放 + 2×投币 + 1.5×收藏** 的对数综合分只挑一条 | 是 |

模型侧看到的完整工具名是 `minecraft-master__wiki_search` 这种（加载器自动加前缀）。

## 触发闸门（为什么平时不打扰）

三道口子共用一个判断（`decide()`），都由核心代码执行，模型绕不过去：

1. `hooks['before-context']` —— 本轮开始时记下"有没有被叫到""有没有聊到 MC"
2. `providers['tool.guard']` —— 没被叫到时**直接否决本技能的工具**，模型连工具定义都看不到
3. `promptSections(ctx)` —— 没被叫到时**不注入**大师提示词，省 token

判定依据（本机 orchestrator 的事实）：`ctx.triggerEntries[].atMe`（是否 @）、`.isPoke`（戳一戳）、`.reply.self`（引用回复机器人）、`ctx.kind === 'private'`（私聊直接放行）。
拿不到本轮信息时（控制台预览、工具页列举）一律放行，否则界面会显示成"工具不可用"，看起来像技能坏了。

## 设置项

| 键 | 默认 | 说明 |
|---|---|---|
| `triggerMode` | 被@或戳一戳时 | 可选"聊到我的世界时""总是" |
| `graceMinutes` | 3 | 被叫到后的宽限时间，期间追问不用再 @ |
| `allowNetwork` | true | 关掉后只用内置速查库 |
| `maxPageChars` | 3000 | 单次返回正文上限（500~12000） |
| `searchLimit` | 5 | Wiki 默认检索条数（1~10） |
| `biliCandidates` | 8 | B 站候选池大小（1~10） |
| `memeEnabled` | true | 允许接梗（只是"可以"，不会硬塞） |
| `includeSource` | true | 结果里附 Wiki 链接 |

## 文件结构

```
skills/minecraft-master/
  skill.json        清单（settings 与 configSchema 必须一一对应，UI 靠它渲染设置页）
  index.js          全部逻辑（工具 / 闸门 / 提示词 / wiki 与 B 站访问）
  kb/*.md           内置速查库（纯数据，离线）
```

**为什么逻辑全堆在 index.js 里、不拆 lib/**：QQ Agent 的热重载只给**入口**文件加防缓存参数（`plugin-loader.js:305`），子模块会被 Node 的 ESM 缓存住 —— 拆到 `lib/` 的文件改完必须重启应用才生效。`kb/*.md` 是纯数据、用 `fs` 读盘，所以放外面没问题（改完热重载即生效）。

## 梗库（08 / 09 / 10 / 11 四篇）怎么扩，以及为什么这么设计

梗库分为四篇：

| 文件 | 内容 |
|---|---|
| `kb/08-梗与黑话.md` | 接龙梗、生物与物品外号、玩法黑话、社区与主播、口头禅、使用原则 |
| `kb/09-官方彩蛋与出处.md` | 游戏内官方彩蛋（命名牌、Minceraft、Technoblade、唱片声谱图），全部可考证 |
| `kb/10-梗库-游戏内梗.md` | 这是特性、翻译事故、操作与生存习惯、合成与物品、赤石科技、界面提示与死亡信息、床/传送门、别的称呼 |
| `kb/11-梗库-圈子与主播.md` | 官方提示与标语、出圈大梗、主播与名场面、外挂与圈内黑话、缩写与专有称呼、**【慎用】别主动提** |

**一行一条**是硬要求，不要写成长段落。两个大库都是逐条改写后的摘要（不是原文照抄），扩库时请沿用这个原则。

**检索方式区别对待**：标题含「梗 / 黑话 / 彩蛋 / 标语」的文档走**行级检索**（`pickMatchedLines`）——抽出所有命中行 + 所属小标题，而不是"从首个命中处截 900 字符"。原因：梗库条目之间没有连贯上下文，按片段截取时库越大越捡不到想要的条目。若查询命中的是小标题（比如查「彩蛋」命中「## 一、命名触发的彩蛋」），会自动补上该节前 4 条，否则只返回标题等于没给内容。

**其他查询不会让梗库抢头名**：查询本身不含梗类意图词（梗/黑话/彩蛋/外号/出处/啥意思…）时，梗库得分打 0.6 折。否则「附魔台怎么摆」会被梗库里的"附魔台摆 15 书架"抢走第一位。

**加新梗的正确格式**（一行一条，别名越多越容易被命中）：

```
- **床是用来炸的 / 床炸**：床在下界和末地使用会爆炸，老玩家拿它开矿、炸末影龙。
```

**扩充数据从哪来**（2026-10 实测）：
- ✅ **`zh.minecraft.wiki` 可用**：`彩蛋`（2.4 万字）、`闪烁标语`（404 条带出处）、`愚人节玩笑`、`A Minecraft Movie` 都能用 `wiki_page` 直接读，API 返回干净 wikitext。
- ❌ **萌娘百科抓不到**：`mzh.moegirl.org.cn`、`zh.moegirl.org.cn`、`m.moegirl.org.cn`、`moegirl.uk`、`moegirl.icu`、`mzh.moegirl.tw` 全部返回 Cloudflare 的 `Just a moment...`（HTTP 403），连 `api.php` 和 `action=raw` 也一样；宿主自带的抓取通道同样超时。**别为了这个加镜像或代理**，会让技能变得不稳定。
- ✅ **人工通道**：萌娘百科「我的世界(游戏)/梗」条目已由人工在浏览器打开、复制正文，再逐条改写成 `10` / `11` 两篇（约 110 条）。**以后想再补，同样走这条路**：浏览器打开 → 复制正文 → 交给助手改写成一行一条 → 保存后热重载生效。不要试图让技能自己去抓。

## 数据来源与已知限制

- **Wiki 正文**来自 `zh.minecraft.wiki` 的 `action=query&prop=extracts`：**表格类内容抽不出来**（合成配方表、掉落概率表、数据值表会看到「Java版：」「基岩版：」后面空着）。这种情况让群友点来源链接看原页，**不要凭记忆补配方**。
- **中文全文检索分词差**：搜「刷铁机」时全文检索会给「生产」「Java版1.8」，所以实现了标题前缀检索优先（`prefixsearch`）。检索结果里若没有任何标题对得上，工具会自动提示模型"换更短的条目名重搜"。
- **B 站投币/收藏数**要逐个取详情（搜索接口只给播放），所以候选池越大越慢；详情接口抖动时会降级为只按播放排序，并在结果里标注。
- 视频只发一条：这是产品决定，避免刷屏。

## 常见问题

| 现象 | 原因 |
|---|---|
| 技能页显示「加载失败」 | 看页面给的原因；清单 JSON 常见问题是多了逗号、或用了 BOM |
| 技能在，但群里 @ 它没反应 | 检查设置页 `triggerMode`；再者工具是否被全局工具开关关掉 |
| 工具显示「不可用」 | 页面会写原因（未启用 / 依赖缺失 / 运行时否决）——"运行时否决"就是本轮没被叫到，属正常 |
| 图/视频搜不到 | `allowNetwork` 是否打开；网络能不能到 `zh.minecraft.wiki` 与 `api.bilibili.com` |

## 改动后怎么验证

改 `index.js`：保存即热重载（看的控制台日志里会有 `[skill] ✅ 加载成功：我的世界大师`）。
改 `kb/*.md`：同样热重载会重新扫描。

自测建议（在项目根目录用 node 跑，`api` 用假的即可）：注册了 4 个工具、`kb_search('梗')` 有结果、`kb_search('creeper')` 命中《梗与黑话》并含「aww man」、`kb_search('还是PVP大佬')` 命中《梗库：圈子与主播》、`kb_search('雷石东直放站')` 与 `kb_search('赤石科技')` 命中《梗库：游戏内梗》、`kb_search('彩蛋')` 命中《官方彩蛋与出处》且给出具体条目（不是只有标题）、`kb_search('钻石在哪挖')` 能靠二元组兜底命中（整句中文查不到是历史缺陷）、`wiki_search('下界合金')` 第一条是「下界合金」、`bilibili_search('我的世界 红石 教学')` 能返回一条带播放/投币/收藏的链接、闸门三态（无信息放行 / 未被叫到否决 / 被 @ 放行）。
