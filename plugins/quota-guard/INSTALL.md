# Token 配额守卫（quota-guard）安装说明

插件版本 1.0.0 ｜ 本包**只含插件代码，不含任何人的额度设置与用量数据**。
装好后额度是空的，需要使用者自己在控制面板里设置。

> **⚠️ 本插件不是自包含的。** 它需要主程序 `src/` 里有两处配合代码
> （`sender.js` 的 `canSend`、`orchestrator.js` 传 `sendState` / `sessionId`）。
> 只放插件文件夹会**整个失效**（拦不住任何人）。
> 如果你是**从打包好的压缩包安装**，请看包里的 `安装说明.md`，
> 那里写清了核心补丁怎么装、怎么备份、怎么回退。

---

## 零、先看这个（最常见的两种情况）

### 情况一：插件页连卡片都没有

插件没被加载。最常见原因是**解压多套了一层**：

```
错的：plugins\quota-guard\quota-guard\plugin.json
对的：plugins\quota-guard\plugin.json
```

把压缩包里的 `quota-guard` 文件夹**整体**放进 `plugins\` 即可，不要再多一层。
放好后重启 QQ Agent（或点插件页的「刷新」）。

### 情况二：卡片出现了，但没有那个小图标按钮，直接开面板地址还是 404

这几乎可以肯定是**文件夹名字不对**：主程序按插件清单里的 id（`quota-guard`）
去找 `plugins\quota-guard\ui` 这个目录。

* 卡片能出现 → 说明插件**加载成功了**（id 取自清单）；
* 没有按钮、地址 404 → 说明主程序按 `quota-guard` 这个名字找不到目录。

**修法**：把文件夹改名成 `quota-guard`，然后重启 QQ Agent。

（用「从安装包导入」装过两次时，QQ Agent 为避免覆盖正在运行的旧目录，
会自动装成 `quota-guard_1`，就是这个原因。）

如果名字已经是 `quota-guard`、`ui` 目录也在，地址仍然 404，说明主程序版本较旧、
不带面板页面功能（面板页面由主程序提供，插件自己装不出来），需要更新 QQ Agent。

## 一、装到哪

```
<QQ Agent 安装目录>\resources\app\plugins\quota-guard\
```

放好后这个路径下应该**直接**能看到 `plugin.json`：

```
plugins\quota-guard\plugin.json      ← 必须在这一层
plugins\quota-guard\index.js
plugins\quota-guard\ui\index.html
```

---

## 二、打开控制面板（不依赖任何按钮）

```
http://127.0.0.1:<端口>/plugin-ui/quota-guard/index.html
```

端口就是平时打开 QQ Agent 控制台用的那个（默认 3210）。这条能打开就说明装对了。

## 三、这个插件干什么

按 **QQ 号**累计每个人每天消耗的 token，超额之后他的消息不再进模型；
一轮里所有参与者都超额时，**连模型都不调用**（一轮零消耗）。
另有**总用量排行榜**，看全部历史谁用得最多。插件自身不消耗任何 token。

三种被拦的情形：

| 情形 | 结果 |
|---|---|
| 有人超额、还有人没超额 | 超额者的发言被剔除，这一轮**照常响应** |
| 参与者**全部**超额 | 跳过这一轮，一条 LLM 请求都不发 |
| **发送限流已满**（每分钟/每小时条数用尽） | 同上，**在请求模型之前**就结束（否则 token 白花） |

**额度周期不是自然日**：默认 `resetHour = 4`，即 04:00 到次日 04:00 算一天，
凌晨 3 点发的消息仍算前一天。

它的"零消耗"依赖主程序提供的能力 `chat.quota-gate`；
**没装或没启用本插件时，主程序那一段是空操作**，行为与没有这套机制时完全一致。

## 四、装好之后要做的两件事

1. **启用**：本插件默认关闭（`enabledByDefault = false`），去插件页把开关打开；
2. **设额度**：控制面板 →「额度管理」→ 逐个添加 QQ 号与每日额度。
   不设时默认额度为 0（= 不限），等于没生效。

设置项（插件页齿轮里）：每日重置时间、默认每日额度、拦下后回一句提示（含提示文本）、
发送限流前置。逐人额度与备注在控制面板里设。

## 五、数据放在哪（重装/升级插件都不会丢）

| 内容 | 位置 |
|---|---|
| 当日账本 | `<数据目录>\quota-guard\ledger.json` |
| 历史累计 | `<数据目录>\quota-guard\cumulative.json` |
| 额度与备注 | `<数据目录>\config.json` → `skills.quota-guard` |

数据目录默认是 `<QQ Agent 安装目录>\data\`（多开实例是 `data-1\`、`data-2\`…）。
**插件文件夹里不会写入任何运行时数据**，所以升级/重装不会丢账本。

> 账本损坏或不存在都会从空账开始，绝不抛错。出问题时直接删掉对应文件即可，
> 它会重建（删掉 `cumulative.json` 会触发一次全量重扫，也可以点页面上的「重新统计」）。

## 六、面板里有什么

* **额度管理**：主从式布局——左边人员列表，点一个人看/改他的独立额度与备注；
* **用量与排行榜**：当日用量、历史累计、被拦次数；
* **重新统计**：重建累计榜（扫描历史会话记录）。
