# 表情包记忆库（sticker-memory）

同一个表情包，只让机器人**认一次**。

群友发过的表情包会按**图片指纹**记住它的含义；以后同一张图再出现（不管是谁在哪个群发的），
系统直接把含义喂给模型，**跳过看图** —— 省掉一次图片上传和一次识图 token，回复也更快。

- 类型：**插件**（`plugins/`，确定性型）—— 由核心在固定时机必然调用，模型想忽略也忽略不掉
- 版本：1.0.0 ｜ API：v1 ｜ 目录：`plugins/sticker-memory/`
- 默认开关：**开**

---

## 装上之后怎么用

**不用配任何东西。** 装上就生效，行为是这样：

| 场景 | 发生什么 |
|---|---|
| 第一次见到某个表情包 | 照常看图识别；看完机器人会把含义记进记忆库 |
| 同一张图再来 | 系统在"要调看图工具"的前一刻拦下它，把库里那句含义**当作工具结果**给模型 —— 图片一个字节都不上传 |
| 含义记错了 | 在群里直接说「这个表情不是这个意思，是……」，机器人会**覆盖**那条记忆 |
| 想让它重新看图 | 「忘掉这个表情的记忆」→ 用 `forget_cached_image` 删掉，下次重新识别 |

它同时管两条链路：**① 群友发进来的表情包**；**② 机器人自己的 QQ 收藏表情**
（库里有备注就不再重复看图）。

## 认图靠什么

QQ 每次下发图片的链接都带会过期的 `rkey`，所以**不能只认链接**。本插件同时记三层键，
任意一层命中即算认识：

```
src:<图片字节 sha1>   最可靠，跨群跨人通用（首选）
file:<OneBot file 字段> 图片标识（文件名 / 资源 id）
st:<表情 id / resId>   收藏表情的身份
```

首见一张图要下载一次字节才能算 `src` 键（此后永久有效）。为了不拖慢对话，解析带预算
（默认 2.8 秒）：超预算就**这一轮不拦截**（照常看图），但下载在后台继续，下一次就命中了。

## 设置项（控制台「插件」页可改）

| 设置 | 默认 | 说明 |
|---|---|---|
| 启用 | 开 | 关掉后一切恢复原样：不拦截、不记录、不联网 |
| 只记表情包 | 开 | 只记表情包/动图表情（按 `[动画表情]` 或小尺寸判断）。截图、照片、带文字的图**不记** —— 再发一次内容可能已经变了，拿旧含义答话比多花点 token 糟得多 |
| 记忆库上限 | 2000 | 超出后淘汰最久未用的条目（一条约 200 字节） |
| 同会话重新确认 | 24 小时 | 一个群里同一张图这个时间内再出现就直接复用；超时重新确认一次。**填 0 = 永不重新确认（最省 token）** |
| 跨会话重新确认 | 7 天 | 在别的群/私聊再遇到时的周期 |
| 跳过识图门槛 | 0.5 | 一条消息多张图时，命中记忆库的比例达到这个值就整条跳过看图 |
| 单次取图预算 | 2800 ms | 首见图算指纹的下载预算，见上文 |

## 给模型的两个工具

| 工具 | 什么时候用 |
|---|---|
| `remember_image` | 看过一张**以前没见过**的表情包后，把「画面里是什么 + 适合什么场合」记下来；群友纠正含义时用它覆盖 |
| `list_cached_images` | 翻记忆库里已记住的图（只读，不消耗识图 token） |
| `forget_cached_image` | 删掉某条记忆，下次重新看图 |

## 运行与安全边界

- **不碰你现有的表情库**：`data/stickers.json` 的权威归程序自己，本插件只读不写，
  避免互相覆盖；表情库备注仍走原来的 `sticker_note` 工具。
- **数据只在本机**：全部状态在 `data/sticker-memory/cache.json`，不含任何密钥、Cookie、账号信息；
  卸载插件后删掉 `data/sticker-memory/` 即可彻底清除。
- **网络**：只做一件事 —— 首次遇到某张表情包时下载一次它的字节来算指纹。
  走**核心的 `safeFetchBinary`**（DNS 全记录内网检查 + 固定 IP 防 rebinding，与项目其它联网模块同源）；
  只有拿不到核心模块时才退回自带的护栏下载器（只放行公网 http(s)、限 12MB、8 秒超时、只收图片响应）。
  除此之外不发任何请求、不上传任何内容。
- **失败也不会打扰对话**：所有钩子内部全程 try/catch，插件出问题只是"没生效"；
  钩子超时（5 秒）由核心跳过并记日志。

## 依赖与权限声明

- Node 内建模块：`node:crypto`、`node:fs`、`node:path`
- 宿主项目模块：`src/config.js`（拿数据目录）、`src/safe-fetch.js`（首选下载器，缺失时自动降级）
- **没有任何第三方 npm 依赖**，不需要 `npm install`，不含模型文件与二进制。
- 清单里的 `permissions` **只声明了 `web_fetch` 一项**（本插件需要下载图片字节来算指纹），
  没有声明任何其它权限；也不含任何 QQ 写操作（不禁言、不撤回、不发消息、不收藏表情）。

## 兼容与回退

- 关闭插件 = 完全恢复原样：不拦截看图、不记录、不联网、内存状态在 `dispose` 里清空。
- 版本要求：QQ Agent 的 Skill API **v1**（与本插件 `apiVersion: 1` 对应）。
