## [1.1.0] - 2026-09-21

**指令改为反斜杠形式，不带反斜杠不生效（含内置工具兜底）**

- 指令：\提醒、\待办（如「\提醒 半小时后拿快递」）
- 清单里开了 `commandOnly` + `commands`，由框架层拦截
- 触发词说明里写明：随口说「提醒我一下」「别忘了」**不响应**
- ⚠️ 同时给 `src/tools.js` 的**内置**提醒工具加了门槛（见下面"为什么"）

**为什么这么写**

- 同 ai-status：用户要求插件指令必须带反斜杠。
- ⚠️ **这个插件差点白改**：提醒功能有两套工具 —— 本插件的 `reminder__set_reminder` 和 `src/tools.js` 内置的 `set_reminder`。
- 内置那套没有 manifest、`skillId` 为空，天然绕过门槛。实测只改插件的话，用户不发「\提醒」照样能设提醒。
- 所以在 `src/skills/command-gate.js` 加了 `BUILTIN_COMMAND_GATE` 表兜住内置工具，指令词跟本插件保持一致（提醒/待办），两边行为才不打架。
- ⚠️ 遗留：两套提醒工具功能重复，是历史问题（本插件 vs 内置）。现在都被同一道门槛管着，行为一致，但仍建议以后合并成一套。

**涉及**：`plugin.json`（commandOnly / commands / prompt.when / examples / description）、`src/skills/command-gate.js`（内置工具门槛表）
**验证**：`node test/command-gate-test.mjs`（21 项全过）；重启后 `GET /api/tools/availability` 确认没带指令时工具为 `enabled=false / code=command-required`
