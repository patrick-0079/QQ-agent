# 发言自检（silent-voice-check）

机器人「既没发消息、也没结束」就结束一轮时，自动判一次：是**确实不想说话**，还是**想说话却忘了走工具**。

## 为什么需要

机器人思考完，文本不会自动发到聊天里，必须调用发送工具。偶尔它思考得很像要说点什么，却没调用发送工具就结束了——用户那边就是「已读不回」。
这个插件不替它发言，只**把一句提醒塞回同一个会话**，让它自己把话说出去。

## 做什么

1. 一轮结束时检查：既没有调用发送工具、也没有调用 `finish`
2. 另起一次**独立的模型调用**做判定，只看这一轮的触发消息 + 它的正文和思考
3. 判定为「漏发」→ 往同一会话注入一句提醒（不是插一句它的话）；判定为「确实不想说」→ 什么都不做
4. 一次运行最多自检一次，避免反复烧 token

## 安装

把本目录放进 QQ-Agent 的 `resources/app/plugins/silent-voice-check/`，重启应用。

需要宿主提供 `llm.request-params` 与 `reply.local-policy` 能力（本插件 manifest 已声明）。

## 设置

| 设置 | 说明 |
|---|---|
| `enabled` | 总开关；关掉后行为与没装一样 |
| `model` | 自检专用模型，留空用聊天模型；填小模型更省钱、也不容易被主模型人设带偏 |
| `timeoutMs` | 自检超时（默认 8000），超时按「确实不想说」处理 |
| `maxTokens` | 自检输出上限（默认 160，它只输出一个 JSON） |
| `minSignalChars` | 正文+思考短于这个字数就直接放过（默认 20），省一次调用；填 0 = 每次都查 |

## 成本

每次触发会多一次小模型调用。只在这一轮「什么都没做」时才触发，正常聊天不受影响。

## 隐私

- 判定内容只发给配置的模型服务商，不额外上传
- 不写任何本地数据文件
