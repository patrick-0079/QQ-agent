好感度插件 · 升档播报素材目录
================================

把「升档时发的那张表情包」放在这个目录里，文件名必须是：

    levelup.png      ← 推荐（也支持 levelup.jpg / levelup.jpeg / levelup.gif / levelup.webp）

放好即生效（热重载：改完插件文件或重启插件都会重新读）。

行为说明
--------
· 只有**正向升档**时才发（降档、平档、日常互动都不发）
· 顺序是：文案（机器人自己那句，按人设）→ 这张表情包 → Ciallo～(∠・ω< )⌒☆
· 每人每天最多播报一次
· 睡眠时段（默认 23:00–12:00）直接丢弃，不补发
· 文件缺失 / 设置里关掉表情包 → **自动降级为只发 Ciallo 那句**，不报错
· 不想发图：设置页把「升档时发这张表情包」关掉即可（只发 Ciallo）

想换文件名 / 用绝对路径：设置里的 `levelUpStickerFile` 填相对本插件目录
（如 `assets/我的图.png`）或绝对路径。
