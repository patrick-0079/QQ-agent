它是怎么工作的

  1. 你把资料按「一本库」放进来（下方可新建、可导入整段文本，也可以直接把 .md/.txt 文件丢进文档文件夹）。
  2. 群友那句话命中某条内容时，宿主机自动把命中的条目塞给机器人参考 —— 这一半不靠它自己想起来。
  3. 机器人也可以主动查（kb_search / kb_list / kb_read 三个工具），聊天里问「群规是什么」它会自己去翻。
  4. 标成常驻的库每轮都会带上，适合群规这种必须一直遵守的内容。
  5. 标成限定范围的库只在指定会话生效（例如只在私聊），在别处连清单都不会出现。
  6. 「调用统计与排行」只做观测：看清楚哪些知识真在被用、哪些从没被用过（调用的多少不会影响命中）。

知识库

左边选一本知识库，这里就会出现它的编辑界面。

新建知识库

创建后是空库，接着在右边的编辑界面里一条条加内容即可。

导入整段文本

把已经写好的资料整段粘进来，会按规则自动切成条目：
· 有 # 标题 就一个标题一条；没有标题就按空行分段；
· 段落里写成 问：… / 答：… 会收成问答对。

命中测试

打一句群里可能会说的话，看看会不会命中知识库、会带哪几条进对话（不会真的发消息，也不消耗 token）。

调用统计与排行

这里只统计，不影响检索：次数与排行不参与打分，不会让任何一条知识因此更容易或更难被命中。 计数来自两种情况：自动带入（回答前自动塞进上下文）与工具检索（机器人主动查）； 读整本（kb_read）按库计一次，不摊到每条。

放文件的地方

正在读取路径…
结构化库是页面里编辑的 *.json； 文档库是丢进 docs 子文件夹的 .md/.txt（一个文件 = 一本库）。 两种都会被自动发现：改完文件不用重启程序，页面点一下「重新扫描」即可。
提醒：知识库正文存在宿主的数据目录里（data/knowledge/），不在插件目录里 —— 升级或重装插件都不会丢。
