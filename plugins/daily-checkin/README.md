# 每日签到 · daily-checkin

群友在群里发「**签到**」就能领金币。每个群独立统计，**每天只能签一次**（按配置时区的自然日 0 点重置，默认北京时间），支持连续签到递增奖励。

金币不另立账本：签到通过宿主的 `currency.v1` 能力直接写进已安装的「**货币系统**」插件，和余额查询、转账、收支流水、财富排行榜**共用同一个钱包**。

## 与其他插件的分工

| 功能 | 由谁提供 |
| --- | --- |
| 发签到金币、连签递增、每天限一次 | **本插件（daily-checkin）** |
| 余额查询、转账、流水、排行榜、主人调账 | 货币系统（currency）自带 |

「货币系统」按设计**不**自动发币（不因发言或签到增发），所以签到需要这样一个业务扩展来接。两者装在一起才是完整的金币玩法。

## 群聊用法

- 「签到」「打卡」—— 领取当天金币，机器人回复：是否首次、连续第几天、这次拿到多少、当前余额。
- 同一天再发一次：照实回复「今天已经签过了」，**不会重复发币**。
- 「我的签到状态」/「签到规则」—— 查询本人连签情况与当前奖励规则（工具 `status`）。

机器人**不能替别人签到**：一次只认本轮唯一发言人的真实消息，引用、转述或别人的消息都不算授权。

## 设置项

**推荐改 JSON 文件** `<数据目录>\daily-checkin\settings.json`
（默认 `E:\QQ agent\data\daily-checkin\settings.json`），存盘即生效、不用重启，文件里带中文注释。

| 键 | 默认值 | 作用 |
| --- | --- | --- |
| `triggerWords` | 签到 / 打卡 / 签到啦 / 每日签到 | 消息包含任一关键词时注入签到任务；留空则不主动触发 |
| `baseReward` | 10 | 每天签到的固定金币数（1~1000000） |
| `streakBonus` | 2 | 连续第 N 天额外加 (N-1)×该数值；0 表示不递增 |
| `maxStreakBonus` | 30 | 连签加成上限，防止老群友收益无限膨胀 |
| `firstBonus` | 0 | 该群第一次签到时额外多发 |
| `timeZone` | Asia/Shanghai | 按哪个时区算自然日（0 点重置） |

也可以写中文键名（`触发关键词`、`基础金币`、`连签加成`……）；以 `$` 开头的行是注释。
写错 JSON 会明确报错并停止发放（不会拿默认值硬跑）；写错个别键名只忽略并提醒。

奖励算法：`基础 + min((连签天数-1) × 连签加成, 加成上限) + 首次奖励`，每次都只发一笔。

## 前置条件（发币权限）

签到需要货币系统把 `credit` 权限授予扩展 `daily-checkin`：

```
插件 → 货币系统 → 扩展接入权限：{"daily-checkin":["credit"]}
```

本插件安装时已自动写入这条授权。如果权限缺失，签到不会静默失败，而是明确回复：

> 签到还没有发币权限：在「插件 → 货币系统 → 扩展接入权限」里填 `{"daily-checkin":["credit"]}` 后保存即可。

## 数据保存

- 连签记录保存在宿主数据目录的 `daily-checkin.json`（`QQ_AGENT_DATA_DIR` / `data-N` 实例互不干扰），金币本身保存在货币系统的 `currency.json`。
- 写入采用「临时文件 + fsync + 原子替换」；文件损坏时**不自动清空**，插件页会显示原因，人工处理。
- 发币的幂等键是 `daily-checkin:QQ号:日期`，所以重复调用、重试、重启都不会重复发币。
- 本插件只依赖货币系统的公开能力接口，不读取它的数据文件。

## 实现要点（给后来改代码的人）

- 落位 `plugins/` 的理由：发币是**确定性规则**，不能交给模型自由发挥；本插件注册工具 + 用 `before-llm-messages` 钩子注入任务，模型想忽略也难。
- `message.trigger` / `settings.text-document` 这类能力名在当前宿主 `src/` 里**没有任何消费点**（eat-what 也提供过，同样不生效），所以唤醒把关放在钩子里，不靠能力名。
- 工具的 `ctx` 没有 `sessionId`/`proactive`/`triggerEntries`；本轮消息在 `ctx.session.trigger`。
- `before-llm-messages` 的钩子上下文里 **有** `sessionId` 与 `triggerEntries`（与工具 ctx 不是同一个对象）。
- 时区一律用 `Intl.DateTimeFormat(..., { timeZone })` 算「自然日」，不要用本地时间或 UTC 日期。
