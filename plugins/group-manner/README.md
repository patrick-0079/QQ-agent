# 群聊分寸（group-manner）

让群里的她**不再句句都接**，只在被叫到或真感兴趣时开口；别人互相说话（尤其是有明确对象的）
默认不插嘴；说话方式向真人靠。

## 为什么群里她句句都回

内核默认 `contextTier = 4`（全部响应）—— 群里**每条消息都会唤醒她**，于是她像客服值班。
内核其实有 1/2/3 档（只响应被@ / 被@+关键词 / 再加随机概率），但"随机"不等于"挑感兴趣的"。

## 这个插件怎么判断

```
① 是不是在跟她说话？  @ 她 / 回复她 / 拍一拍 → 必回（绕过一切概率）
② 有没有明确说话对象？ @ 了别人 / 回复别人 / 点名问某人（"张三你觉得呢"）→ 不插嘴
③ 其余情况按兴趣加权掷骰子：
     基础 15%
     + 命中兴趣词   +35%
     + 是问句       +20%
     + 带情绪       +15%
   → 掷到就允许她接一句，没掷到就让她安静
④ 外加最短间隔（默认 45 秒），防止她连着插话；被叫到不受限
```

判定**只认结构化字段**（`atMe` / `reply.senderId`），不做名字匹配 —— 名字会改会撞，
这和 speaker-identity / 伴侣认证是同一套口径。文本启发式只用在"点名问某人"上，且写得很保守。

## 为什么不用改内核

内核本身就支持"看完消息决定不回，就安静结束"（`src/prompt.js` 规则 5，模型返回空即不发言）。
所以插件只需要**把"现在该不该开口"讲清楚**，执行交给内核原有的空回复路径 —— **零内核改动**。

## 还有一半：像真人说话

光少说不够，还得像人。插件会注入这段口径：

> - **短**：一两句，通常 3~30 字。群里没人发长篇大论。
> - **口语**：可以用「啊/吧/诶/草/哈哈/？？？」，可以说半句话。
> - **有情绪**：好笑就笑，无语就吐槽，被逗到可以直接「草」。
> - **不客服腔**：绝不说「有什么可以帮您」「感谢分享」「希望对你有所帮助」。
> - **不复读**：别人刚说过的意思不要再重复。
> - **允许不接**：没什么想说的就安静待着 —— 不用为了合群硬找话题。

## 设置项

| 设置 | 默认 | 说明 |
| --- | --- | --- |
| 启用 | 开 | |
| 只管群聊 | 开 | 私聊里她说每句都是对的，不该套群里的分寸 |
| 没被叫到就别接 | 开 | 有明确对象时不插嘴 |
| 搭腔基础概率 | 15% | "偶尔"的基准值 |
| 她感兴趣的话题词 | 画画/代码/游戏… | 命中显著提高开口意愿 |
| 是否问句加成 | +20% | |
| 带情绪加成 | +15% | |
| 命中兴趣词加成 | +35% | |
| 说话方式补充 | 空 | 留空用内置口径，写了会拼在后面 |
| 两次主动搭腔最短间隔 | 45 秒 | 被叫到不受限 |
| 只管主人的群 / 只对这些 QQ 生效 | 关/空 | 范围限定 |

## 💡 想更省 token

插件让模型"决定不回"仍然要跑一轮模型。如果你的群消息量很大，可以再去内核设置里把
**群聊的 `contextTier` 调成 3**、`randomPercent` 调低 —— 那样连"要不要唤醒她"都在本地判掉了，
两者搭配效果最好（插件管"唤醒了之后该不该说"，内核管"要不要唤醒"）。

## 面板

设置页 →「群聊分寸」：各项参数、兴趣词、她最近在哪个群开过口，以及每次决策的原因
（日志里也会逐条记：`[group:xxx] 开口/安静｜基础 15%，命中兴趣词「画画」+35% → 掷到 22，这次接一句`）。
