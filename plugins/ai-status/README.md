## 安装

把 `plugins/` 下的**每个插件文件夹整个**放进你的 QQ-agent-0.4 的 `plugins/` 下，
然后**重启机器人** —— 提示词、工具和能力都是加载期注册的，热重载管不到。

```
QQ-agent-0.4/
└── plugins/
    ├── ai-status/
```


## AI状态查询 v1.6.0（目录 `plugins/ai-status/`）

查询机器人当前状态并发送一张状态面板图：模型与渠道显示中文品牌名（deepseek-v4-pro → 深度思索 v4-pro 等，映射表内置主流厂商可随时补充）、今日 token 用量与缓存命中率、今日花费、今日会话、运行时长、DeepSeek 峰谷时段与转档倒计时、日志告警、最近节日倒计时、系统资源（进程内存/堆、系统内存余量、CPU 占用，超阈值时给出重启建议）、插件状态（其他插件通过 status.<插件id> 能力上报自己的运行状态，自动聚合显示）、亮暗配色切换（theme 设置项）。图片由工具直接发出（渲染失败自动回退文字卡）。另对外开放 cost.display-override 能力：别的插件可以只改「今日花费」的**显示文案**（真实计费与预算统计不受影响）。用法：发「状态」「AI 状态」「用量」「花费」，或直接 @机器人 问一句即可。

| 字段 | 填什么 |
|---|---|
| — | 见控制台表单 |

> **会用到别的插件的能力**：`llm.rate-stats`、`cost.display-override`、`message.owner-check`
> —— 有提供方就用，没装就自动跳过；插件其余功能照常，不报错。

## 填配置（必须先填）

`config.example.json` 是配置样例，**不是拿来直接覆盖 `data/config.json` 的**。
装好后打开控制台 → 插件页 → 点卡片看右侧详情里的表单，就地改就地存。

⚠️ **密钥类字段（token / password / apiKey）在样例里留空**，留空等于关闭对应功能，不会报错。
⚠️ 别手改 `data/config.json` —— 内存里有缓存，改了不生效，还会被控制台页面覆盖回去。
   一切走控制台界面，或 `POST http://127.0.0.1:3210/api/config`。

包里带了测试脚本：
- `test/ai-status-test.mjs`（AI状态查询）

它们 import 的是项目里的相对路径 ——
把插件文件夹放进 QQ-agent-0.4 后，把测试文件也放进项目的 `test/` 目录，再跑
`node test/<名字>-test.mjs`。
