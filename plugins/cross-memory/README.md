# 仿生记忆（cross-memory v2）

让她的记忆**在所有会话之间互通**，而且**像人一样**——不是数据库那样把最近的话倒出来。

## 先说 v1 差在哪

v1 是"把她最近说过的话按时间倒序取几条塞进上下文"。它有三个毛病：

- **机械**：48 小时窗口内的一视同仁，窗口外的一刀切
- **每次都全量**：不管你在聊什么，塞的都是同几条最近的
- **没有主次**：昨天踩坏的键盘和三个月前的那句"我很难过"待遇一样

那是数据库，不是记忆。所以 v2 按人脑记忆的特性重做。

## 六条仿生特性

### ① 遗忘曲线

每条记忆有**强度**，随时间指数衰减（半衰期默认 36 小时）：

```
2 小时前 ···· 0.95      ← 清清楚楚
36 小时前 ··· 0.50      ← 记个大概
72 小时前 ··· 0.25      ← 有点印象
一周前 ····· 0.02      ← 快忘了（低于 0.04 直接删掉 = 真的遗忘）
```

强度低到阈值以下的会被**删除**——这是真正的遗忘，不只是"不提起"。

### ② 情绪加权

让她有情绪的事，半衰期最多延长 2.5 倍：

| 内容 | 检测到的情绪 |
| --- | --- |
| 「气死我了！！！」 | 0.55 |
| 「哈哈哈哈哈这也太好笑了」 | 0.45 |
| 「我把文件放桌上了」 | 0.00 |

同为 40 小时前的两条，高情绪的强度 **0.60**，无情绪的 **0.33**——人就是记得住让自己有情绪的事。

### ③ 联想检索（最关键的一条）

不再按时间倒序全量取，而是拿**你正在聊的话题**去匹配记忆，按分数取前几件：

```
分数 = 相关度 × 0.55  +  强度 × 0.30  +  新鲜度 × 0.15
        ↑ 主导
```

相关度用**两条通道**取强者：

- **n-gram 命中**（精确：「画画」↔「画画」）
- **字符级 Dice 相似度**（模糊：「上班」↔「加班」这种不共享词但共享字的情况）

只靠前者太脆，只靠后者太松。

**毫无共同点就不想起来**——人不会在聊量子力学时突然说"我刚吃完饭"。
（想主动找话说那是 her-life 的事，不该由记忆系统硬塞。）

实测（权重调对之后）：

| 你问 | 她想起 | 分数 |
| --- | --- | --- |
| 你最近还在画画吗 | 「我最近在学画画，画了一只猫」 | 0.58 |
| 今天上班累吗 | 「今天加班到十点，累死了」 | 0.49 |
| 量子场论的重整化 | （不想起任何事） | — |

注意第二行：更近的那条是「我家猫踩坏键盘」（30 小时前），但它只是**同一天说过**，
所以输给了 70 小时前那条高度相关的。**相关度主导，不是新的先冒头**。

### ④ 复习效应

某条记忆被想起一次，强度就 +0.12（累计上限 0.6）。

衰减的起点取「事件发生」与「上次想起」里**更晚的那个**——回忆会重新巩固记忆。
但**细节**仍按真实年龄淡去（见 ⑥）。这个分工是刻意的：

> **熟悉感可以恢复，细节照样会忘。** 就像你想起一个老朋友，觉得亲切，但想不起他那天穿什么。

### ⑤ 记忆巩固

**反复被想起的事**会升级成**长期记忆**（衰减慢 6 倍）：

- 想起 ≥ 3 次 → 升级（主判据：人记住一件事靠的是反复提取，不是它当时多强烈）
- 或：强度 ≥ 0.62 且至少想起过 1 次 → 升级（加速通道）

实测 100 小时后：短期记忆剩 **0.09**，长期记忆还有 **0.94**。

### ⑥ 细节模糊化

越久远的记忆，给她的时候越简略：

```
1 小时前 ···· 给 100 字（完整）
200 小时前 ·· 给 35 字（梗概）
```

人对旧事的印象本来就是梗概，不会记得原话。

## 注入长这样

```
【你想起了一些事（由现在聊的内容想起来的，不是全部）】
· 10-11 23:00（那个群里）你说过「我最近在学画画，画了一只猫」（这事你一直记着）
· 10-13 14:00（那个群里）你说过「我家猫今天把我的键盘踩坏了」
（自然带出来就行，别复述时间地点，也别说「我记得」这种话 —— 就跟人聊天时顺口提到一样。）
```

最后那句引导很重要：否则她会生硬地"念记忆"，比不记还假。标题也特意写明"**不是全部**"，
免得她以为这就是她全部的记忆。

## 隐私（沿用 v1 的默认）

只记 `self: true` 的内容（**她自己说过的**）。别的会话里别人说的原话默认不记 ——
群里 A 说的话，A 并不知道会被带到你私聊里。要记得自己开开关。

## 数据存在哪

```
data/cross-memory/memories.json
```

删掉它就等于"让她失忆"（会从聊天存档重新采集，但强度、情绪、长期记忆的积累会重置）。

## 实测

29 项测试通过（含六条特性各自的验证）：增量采集不重复、遗忘曲线单调且幂等、
情绪加权、联想检索换话题想起对应的事、无关话题完全沉默、复习效应、长期记忆巩固、
细节模糊化、真遗忘、注入文本与隐私默认。

## 依赖

只读聊天存档（`data/messages/`）和内核整理的印象（`data/memory/`）。
**不改内核、不需要重启、不花 token**（采集与检索全是本地计算）。
