# 安装说明（《复仇账本》v1.7.0）

三步，两分钟。**不需要装任何依赖**，也不会动你原来的任何东西（装上是个空账本）。

---

## 一、解压

把压缩包解开，里面只有一个目录：

```
revenge-ledger/
├─ plugin.json      ← 技能清单
├─ index.js         ← 全部代码
├─ README.md        ← 详细说明（有设置项逐个解释）
└─ 安装说明.md       ← 就是本文件
```

---

## 二、放进去

把整个 **`revenge-ledger` 目录**（不是里面的文件）放到：

```
<你的 QQ Agent 安装目录>\resources\app\skills\
```

放好之后应该长这样：

```
...\resources\app\
├─ plugins\        ← 不用管这里
└─ skills\
   ├─ (你已有的其它技能…)
   └─ revenge-ledger\
      └─ plugin.json
```

👉 **认不准位置就看这一句**：让它和 `skills` 文件夹里**其它技能目录并排**就对了。
👉 目录名**保持英文 `revenge-ledger`**，别改中文名。
👉 如果你那边的客户端支持「从 zip 安装技能 / 安装包」，也可以直接选这个压缩包装（包内结构是按这个格式打的）。

---

## 三、生效

回到控制台 **重扫技能**（或者重启 QQ Agent）。

看到日志里有这一行就成功了：

```
复仇账本已加载（v1.7.0）｜工具 revenge_add / revenge_query / revenge_settle｜报幕档 sharp｜…
```

然后在群里随便说一句「记你一笔」，或者问它「账本上都记了谁」，看它会不会去调工具。

## 想调一调？（都能在设置页点，不用改代码）

| 想干嘛 | 改哪个 |
|---|---|
| 换报幕的语气 | **报幕文案档位** `noticeFlavor`：`sharp`（默认，中性锋利）/ `limbus`（《边狱巴士》中指致敬档） |
| 少喊几句 / 多喊几句 | `noticeDailyCap`（默认一天 3 次）、`noticeCooldownMinutes`（默认至少隔 6 小时） |
| 完全不喊报幕 | `noticeDailyCap` 设 `0`（记账照常） |
| 让它更主动去记账 | `nudgeEnabled` 打开（默认关，怕白花 token） |
| 想用自己的口气 | 打开 `index.js` 搜 `NOTICE_FLAVORS`，把 `sharp` 档的句子换成你家 AI 会说的（**保留 `{n}`**） |

## 常见问题

**放了但工具列表里没有？**
九成是目录多套了一层。必须是 `skills\revenge-ledger\plugin.json`，
不能是 `skills\revenge-ledger\revenge-ledger\plugin.json`，也不能把文件直接散在 `skills\` 里。

**账本数据在哪？**
`data\revenge-ledger.json`，纯明文，随便看、随便改。删掉 = 账本清空。
（本压缩包里**没有任何数据文件**，你的是你的。）

**它会拿这个真去报复谁吗？**
不会。它只是让 AI 记着、偶尔嘴上念叨一句。提示词里明确写了：别当真威胁、别记真实隐私。

**不喜欢 / 想删掉？**
删掉 `skills\revenge-ledger\` 整个目录，重扫技能即可。想连账本一起清掉就再删 `data\revenge-ledger.json`。

## 还是装不上？

回群里说清楚三件事，基本一眼就能定位：

1. 你的目录结构截图（到 `skills\` 那一层，让我们能看到里面的目录名）；
2. 启动日志里搜「复仇账本」出现的那几行（有报错就贴报错）；
3. 你的 QQ Agent 版本号、是 Windows 还是别的系统。
