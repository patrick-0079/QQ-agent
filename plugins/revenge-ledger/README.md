# 《复仇账本》· revenge-ledger v1.7.0

给你的 AI 配一本**玩笑性质**的「记仇小本本」：

> 群友惹到它、阴阳它、鸽了它、欠着没还、说话太损 → 记一笔（谁、因为什么、仇恨值 1~5 星）；
> 对方道歉 / 补偿 / 事情翻篇 → 销账。
> 账本还会自动统计各种**纪录**（单笔最高仇恨、最快三连、最速回锅、被记笔数最多、累计仇恨榜首…）。
> **只有有人刷新纪录时才让它喊一声 —— 而且喊得很少**（默认一天最多 3 次）。

这是一个**通用技能**：不含任何人的数据、不依赖任何人设、装上是空账本，谁的机器上都是同一套机制。

---

## 1. 它是什么 / 不是什么

| 是 | 不是 |
|---|---|
| 一个 LLM 型技能（skill），注册 3 个工具，由**模型自己判断**什么时候记 / 查 / 销 | 不是自动报复、不是定时任务，不经过模型就不会动 |
| 纯本地明文 JSON 存档，随时能打开看、改、删 | 不上传、不联网、不写别的地方 |
| 群里的梗：锋利、但不真伤人 | 不是真威胁，也不该记真实隐私（住址 / 电话 / 证件 / 单位） |

装好之后**没有自带账目**：第一次记账时才会生成数据文件，从零开始。

---

## 2. 装在哪

丢进 **`skills/`**（不是 `plugins/`）：

```
<你的 QQ Agent 安装目录>/resources/app/
├─ plugins/        ← 确定性插件（按能力调用）
└─ skills/         ← LLM 型技能（注册工具给模型用）
   ├─ (其它技能…)
   └─ revenge-ledger/          ← 就把这个目录放这里
      ├─ plugin.json
      ├─ index.js
      ├─ README.md
      └─ 安装说明.md
```

* 目录名请保持英文 **`revenge-ledger`**（= `plugin.json` 里的 `id`），别改成中文名。
* 如果你不确定该放哪：**放到与其它技能（`skills` 文件夹里的那些目录）同一层**就不会错。
* 本压缩包的结构（单一根目录 `revenge-ledger/`）正好是客户端「从 zip 安装」认的格式
  （安装时会自动剥掉这层同名根目录，落到 `skills/revenge-ledger/`），
  所以**手动拷贝整个目录**和**用安装入口装 zip** 两种都行。

---

## 3. 怎么生效

1. 放好目录；
2. 到控制台**重扫技能**（或重启 QQ Agent）；
3. 启动日志里出现这行就是成功：

   ```
   复仇账本已加载（v1.7.0）｜工具 revenge_add / revenge_query / revenge_settle｜报幕档 sharp｜报幕：冷却 360 分钟 / 每日上限 3 次 / 单项 1440 分钟｜nudge：关（默认）
   ```

数据文件在 `data/revenge-ledger.json`（首次记账时生成）。**删掉它 = 账本清空**，不影响技能本身。

## 4. 三个工具

| 工具 | 作用 |
|---|---|
| `revenge_add` **记一笔仇** | 谁（QQ 号或昵称）、因为什么、仇恨值 1~5 星、可选证据原话。同一个人同一件事重复记会**自动合并**（仇恨值累加），不用怕记重 |
| `revenge_query` **翻复仇账本** | 按人 / 按状态（未销 · 已销 · 全部）列出；`mode=rank` 出**仇恨榜**；`mode=records` 看当前各项纪录保持者 |
| `revenge_settle` **销一笔账** | 按编号（`e12`）或按人销账（销掉他所有未销账记录），可写备注（例如「请了奶茶」） |

## 5. 设置项逐个说明

在控制台 → 技能 → 复仇账本 →（齿轮）设置，全部可视化修改。

| 设置项 | 默认 | 说明 |
|---|---|---|
| `noticeFlavor` | `sharp` | **报幕文案档位**（下拉框）。`sharp` = 中性但锋利，不依赖任何人设；`limbus` = 原作致敬档。见第 7 节 |
| `maxEntries` | `200` | 账本最多留几笔。超出后**先淘汰最旧的已销账记录**，仍然超才淘汰最旧的未销账记录（不会静默丢刚记的仇） |
| `defaultWeight` | `1` | 记一笔时没写仇恨值就用这个（1~5 星） |
| `noticeCooldownMinutes` | `360` | 报幕冷却：两次报幕至少隔 6 小时。填 `0` = 不限制这一项 |
| `noticeDailyCap` | `3` | **报幕每日上限**：一天最多报 3 次。填 `0` = 一天一次都不报（等于关掉报幕，但**记账 / 查询 / 销账完全正常**） |
| `noticeKeyCooldownMinutes` | `1440` | **同一条纪录**的报幕冷却：最快三连这种纪录 24 小时内不重复报 |
| `nudgeEnabled` | `false` | **关键词提醒开关，默认关**。打开后：只有当**本轮对方说的那句话**命中账本关键词（账本 / 小本本 / 记仇 / 翻旧账 / 销账 / 记一笔…）时，才在这一轮请求末尾补一句「该动账本了」。默认关是为了不白花 token |
| `nudgeCooldownMinutes` | `240` | 提醒冷却：同一个会话两次提醒至少隔 4 小时 |
| `nudgeDailyCap` | `2` | 提醒每日上限：所有会话合计一天最多贴 2 次。填 `0` = 一次都不贴 |

**想让报幕更少 / 更多**：改 `noticeDailyCap`（一天几次）和 `noticeCooldownMinutes`（至少隔多久）。
**想彻底关掉报幕**：`noticeDailyCap = 0`。**想让账本更主动**：`nudgeEnabled = true`。
设置改完即时生效（每次报幕/提醒都现读设置）；如果你的版本没刷新，重扫一次即可。

## 6. 8 类纪录 + 为什么报幕是稀有的

自动统计：单笔最高仇恨、最快三连（连吃三笔）、最速回锅（刚洗白又被记）、被记笔数最多、
累计仇恨榜首、同一件事被记最多次、最快洗白（记上到销账）、陈年旧账（最久没销）。
每条纪录都配一个「复仇账簿条款号」（如 `第72条第3项D行第4列`），报幕时会被填进 `{n}`。

**报幕降频（noticeGate）** —— 为什么必须有：陈年旧账的数值 = 现在 − 最早未销那笔的时间，
**它自己每秒都在变大**，所以只要账上有一条旧账，每记一笔 / 每销一笔都会被判定成「打破纪录」，
报幕频率 = 记账频率。闸门只决定「这次的报幕稿要不要交给模型喊」，
**不动记账判据、不动纪录算法、不动销账判据**：

| 旋钮 | 默认 | 作用 |
|---|---|---|
| 全局冷却 | 360 分钟 | 两次报幕至少隔 6 小时 |
| 每日上限 | 3 次 | 一天最多报 3 次 |
| 单项冷却 | 1440 分钟 | 同一条纪录 24 小时内不重复报 |
| 纯时钟纪录 | 内置 | 旧账只是「变老」不算新闻，**只有旧账区换人才算** |

冷却是「丢掉」不是「排队补发」—— 被挡住这次就没了，不会在解除冷却时一次性炸一堆。

## 7. 报幕文案：两档可选

报幕稿长这样（第一行是给模型看的事实，第二行是**给它照着说的台词**）：

```
【账簿】第27条第5项｜新纪录｜最快三连（连吃三笔）｜某人｜2 分钟
—— 翻到 第27条第5项 你就知道了。
→ 用你自己的口气把这句说出来，一句话就够，别念整张表、别念成公告、别演成真的威胁。
```

两档只换**说话方式**，骨架一样（`【账簿】` 抬头、条款号、`如数奉还` / `中指时刻铭记` / `永不遗忘` 这些锋利感都留着）：

**`sharp`（默认档，中性但同样锋利，不依赖任何人设）**

```
—— 啧。又够一页了。你名字快写满这本。
—— 记上了。该还我的，又多一笔。
—— 哼，刻上去的擦不掉。别指望我忘。
—— 翻到 {n} 你就知道了。
—— 算了……啧。也写进账簿里吧。
```

**`limbus`（原作致敬档：《边狱巴士》「中指」《复仇账簿》的口气）**

```
—— 依据{n}，此笔已记于账簿之上。
—— 中指时刻铭记。这笔账，永不遗忘。
—— {n}。已归档；如数奉还，只是时间问题。
```

**怎么切**：设置页 → 复仇账本 → **报幕文案档位**（`noticeFlavor`）→ 选 `sharp` / `limbus` 即可，默认 `sharp`。

## 8. 怎么改成自己 AI 的口气

打开 `index.js`，搜 **`NOTICE_FLAVORS`**，把 `sharp` 档里的句子换成你家 AI 会说的话就行（`limbus` 档留着当彩蛋，也可以一起改）。
规则只有两条：**保留 `{n}`**（它会被替换成条款号），**句子短、别写成公告**。
改完重扫一次技能即可，账本数据不受影响。

## 10. 常见问题

**Q：装了没反应，工具列表里没有？**
A：① 确认目录层级是 `…/resources/app/skills/revenge-ledger/plugin.json`（多套一层目录是最常见的原因）；
② 控制台重扫技能或重启；③ 看日志有没有 `复仇账本已加载`，或技能页有没有显示「加载失败 + 原因」。

**Q：会不会乱花 token？**
A：默认不会。关键词提醒（nudge）默认关；报幕一天最多 3 次，而且只在真的有纪录被刷新时才出现。

**Q：账本数据在哪？会跟着包一起发出去吗？**
A：`data/revenge-ledger.json`，纯明文。本技能包**不含任何数据文件**，装上就是空账本。

**Q：能记真名 / 电话吗？**
A：别。它是群里的梗，提示词里已经写明不要记真实隐私。
